# Customer Churn & Categorical Data Preprocessing Demo

This repository contains a Jupyter Notebook for a Week 5 graded activity about handling categorical data in machine learning.

## Project Goal

The notebook demonstrates how to prepare categorical and numerical data before training a simple machine learning classification model.

The main ideas covered are:

- Creating small example datasets
- Identifying categorical and numerical columns
- Separating nominal and ordinal categorical features
- Handling missing values
- Encoding categorical variables
- Scaling numerical variables
- Building a preprocessing pipeline
- Training and evaluating a classification model

## Main Dataset Idea

One of the examples uses a customer churn dataset.  
A churn dataset is used to predict whether a customer will leave a company or stay.

In this project:

- `Churn = Yes` means the customer left
- `Churn = No` means the customer stayed

The model uses features such as contract type, payment method, satisfaction level, monthly charges, and tenure months to predict churn.
